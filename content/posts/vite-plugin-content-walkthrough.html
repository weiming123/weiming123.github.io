自研 Vite 插件管理本地文章

这个博客的文章编辑后台只在本地开发环境存在，生产构建中完全不可见。核心是两个 Vite 插件。

dev：中间件提供 API

开发服务器上注册 /__admin/api 中间件：

  • GET /__admin/api/index 读取全量索引（含草稿）
  • POST /__admin/api/post 保存文章：渲染 markdown 为 html，写入 content/ 目录
  • DELETE /__admin/api/post/:id 删除文章

build：closeBundle 过滤草稿

构建时把 content/ 中已发布的 md / html / 图片复制进 dist/content/，草稿永远留在本地。

前端如何剔除管理代码

if (import.meta.env.DEV) {
  routes.push(/* 管理后台路由 */);
}

生产构建的 tree-shaking 会把整个分支删掉，管理页面代码不会出现在产物中。
